## Neural Radiance Fields (NeRF)
<img width="738" height="678" alt="image" src="https://github.com/user-attachments/assets/713753ec-e9e0-4d02-b50c-6b445b9ef399" />

Implemented a novel view synthesis program based off of [the NeRF paper]([url](https://arxiv.org/abs/2003.08934)). Each point is represented as a 5-dimensional coordinate, with the position and viewing angle encoded. While this method can be improved to work better for reflective or partially translucent objects, it is a generalizable representation that learns color and density along rays, and generate entirely novel views of an object.
